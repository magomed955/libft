# Libft

Libft is a custom C library developed as part of the 42 curriculum.
The project consists of reimplementing standard C library functions to better understand
their underlying mechanisms and build a reusable collection of utilities.
It includes functions for string manipulation, memory management, character handling,
and type conversions, with an optional bonus section for linked list operations.
This project strengthens core C programming skills, pointer manipulation, memory allocation,
and low-level programming fundamentals.

**Technologies:** C, Makefile, Git.
